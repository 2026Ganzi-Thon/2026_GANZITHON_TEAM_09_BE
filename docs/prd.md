## 1. 목적과 범위

**한 줄 정의:** 기분을 한 번 탭하고, 각자 작은 미션을 하며 그룹 캐릭터를 함께 키우고, 힘든 날엔 실제 공공 지원으로 이어주는 모바일 웹앱(PWA).

**MVP에 넣는 것**

| 영역 | 내용 |
| --- | --- |
| 계정 | 로그인 없는 익명 계정, 민감정보 동의, 데이터 삭제 |
| 그룹 | 친구(초대 코드)·온라인(자동 배정)·1인 그룹, 나가기, 신고·차단 |
| 기분 | 하루 1회 기분 입력, 3일 연속 낮은 기분 카드 |
| 미션 | 하루 개인 미션 1개, 크기·밖/안 선택, 타이머, 완료 |
| 핑·캐릭터 | 완료 후 이모티콘 핑 1회, 그룹 캐릭터 성장·완성·도감 |
| 점검 | 일요일 저녁 주간 점검 4문항, 결과 문장과 연결 |
| 도움받기 | 전국 사업 카드 + 서울 지역 사업 카드, 기기에서 필터, 오프라인 |
| 알림 | 웹 푸시(미션 알림, 일요일 점검 알림) |
| 시연 | 실서버는 출시 그대로(시계 조작 없음), 며칠이 걸리는 장면은 프론트 목업에서 기기 시계로(D-12) |

**MVP에 넣지 않는 것:** 로그인·소셜 로그인, 기기 옮기기, 그룹별 미션, 그룹 안 텍스트·사진·채팅, 캐릭터 퇴화, 날씨·대기질 API, 야간 규칙, 서울 밖 지역 사업, 신청 대행·예약·진행 관리, 관리자 화면.

## 3. 용어

| 용어 | 정의 |
| --- | --- |
| 하루 | 한국 시간(KST) 00:00:00 ~ 23:59:59. 서버의 모든 날짜 계산은 KST 날짜(`LocalDate`)로 한다 |
| 주 | KST 월요일 00:00 ~ 일요일 23:59 |
| 익명 계정 | 첫 실행 때 서버가 만드는 계정. 이름·이메일·전화번호가 없다 |
| 낮은 기분 | `TIRED`(지쳐요)·`DEPRESSED`(우울해요)·`LONELY`(외로워요) |
| 연속 | 날짜가 하루도 빠짐없이 이어진 것. 기분을 입력하지 않은 날이 있으면 끊긴다 |
| 완료 | 그날 개인 미션에 '다 했어요'를 누른 것. 하루 최대 1회 |
| 구성원 | 그룹에 현재 속한 사용자. 나간 사람·자동으로 내보내진 사람은 아니다 |
| 성장 수치 | 캐릭터 진행도. 0 이상 100 이하. 100이면 완성 |
| 확정 성장 | 하루가 끝난 뒤(00:00 처리) 확정한 그날의 성장 |
| 임시 성장 | 오늘 지금까지의 완료로 계산한, 화면 표시용 성장 |
| 접속 | 인증된 API 요청 1건 이상 |

## 4. 사용자와 권한

| 행위자 | 할 수 있는 것 |
| --- | --- |
| 계정 없는 방문자 | 도움받기 목록 보기 |
| 익명 사용자 | 자기 기분·미션·점검·기록, 그룹 만들기·참여 |
| 그룹 구성원 | 그 그룹의 캐릭터·완료 현황·핑·구성원 별칭 보기, 신고·차단, 나가기, (친구 그룹) 초대 코드 만들기 |
| 만 19세 이상 확인자 | 온라인 그룹 대기열 들어가기 |

- 기분·점검 기록은 **본인만** 읽는다. 어떤 그룹 API 응답에도 들어가지 않는다.
- 구성원이 아닌 그룹을 요청하면 **항상 404**로 응답한다. 403을 주면 그 그룹이 있다는 것이 드러나 그룹 ID를 추측할 수 있기 때문이다.

## 5. 기능 요구사항

### 5.1 계정 (ACC) — 담당 A

| ID | 요구사항 | 완료 기준 |
| --- | --- | --- |
| ACC-01 | 첫 실행 때 익명 계정을 만들고 세션 토큰을 HttpOnly·Secure·SameSite=Lax 쿠키로 준다 | 쿠키 없이 계정 생성 요청 → 201, `Set-Cookie`에 HttpOnly·Secure가 있다 |
| ACC-02 | 토큰은 256비트 이상 무작위 값이고, 서버에는 SHA-256 해시만 저장한다 | DB에 토큰 원문이 없다 |
| ACC-03 | 계정 생성은 IP당 시간당 10회까지 | 11번째 요청 → 429 |
| ACC-04 | 닉네임은 1~10자, 공백만은 안 된다. 바꿀 수 있다 | 11자 → 400 |
| ACC-05 | 민감정보(기분·점검) 수집 동의를 따로 받는다. 동의 없이는 기분·점검 저장 요청이 403 | 미동의 상태 기분 저장 → 403 `CONSENT_REQUIRED` |
| ACC-06 | 동의를 철회하면 이후 기분·점검을 받지 않는다. 기존 기록은 삭제 요청 때 지운다 | 철회 후 기분 저장 → 403 |
| ACC-07 | 기분·점검 기록만 삭제할 수 있다 | 삭제 후 기록 조회 → 빈 목록 |
| ACC-08 | 계정을 삭제할 수 있다. 모든 그룹에서 나가고 개인 기록을 지운다. 그룹 캐릭터·도감은 남는다 | 삭제 후 같은 쿠키로 요청 → 401 |
| ACC-09 | '만 19세 이상이에요' 자기 확인을 저장한다(생년월일은 받지 않는다) | 확인 전 온라인 대기열 요청 → 403 `ADULT_CONFIRMATION_REQUIRED` |
| ACC-10 | 인증된 요청마다 `last_seen_at`을 갱신한다(같은 시간대 안에서는 1번만 쓴다) | 요청 후 `last_seen_at`이 1시간 안의 값이다 |

생년월일·거주 지역·지금 하는 일은 **서버로 보내지 않는다**(기기 저장, 도움받기 필터 전용).

### 5.2 그룹 (GRP) — 담당 A

| ID | 요구사항 | 완료 기준 |
| --- | --- | --- |
| GRP-01 | 그룹 종류: `FRIEND`(2~6명), `ONLINE`(4~6명), `SOLO`(1명) | — |
| GRP-02 | 한 사용자는 그룹 최대 3개. 온라인 대기 중인 자리도 1개로 센다 | 그룹 3개인 사용자의 생성·참여·대기 요청 → 409 `GROUP_LIMIT` |
| GRP-03 | 친구 그룹은 만든 사람이 이름(1~12자)을 정한다. 만들면 바로 구성원 1명이다 | 생성 → 구성원 1명 |
| GRP-04 | 친구 그룹 구성원은 초대 코드를 만들 수 있다. 코드는 영문 대문자·숫자 8자(혼동 문자 0·O·1·I 제외), 7일 뒤 만료, 새로 만들면 이전 코드는 무효 | 만료 코드로 참여 → 410, 무효 코드 → 404 |
| GRP-05 | 초대 코드 참여는 IP당 시간당 20회까지 | 21번째 → 429 |
| GRP-06 | 6명인 그룹에는 참여할 수 없다 | → 409 `GROUP_FULL` |
| GRP-07 | 온라인 대기열: 먼저 4~5명인 온라인 그룹의 빈자리를 채운다(인원이 적은 그룹 먼저). 빈자리가 없으면 대기하고, 대기자가 4명이 되면 새 그룹을 만든다 | 대기자 4명째 요청 → 4명 모두 같은 새 그룹에 배정 |
| GRP-08 | 온라인 그룹 이름은 미리 정한 목록에서 무작위로 붙인다(예: 아침 산책단) | — |
| GRP-09 | 그룹 안에서 구성원은 그룹 전용 `memberId`로 가리킨다. 사용자 ID는 응답에 넣지 않는다 | 그룹 API 응답에 `userId` 필드가 없다 |
| GRP-10 | 온라인 그룹 구성원은 그룹마다 따로 정한 랜덤 별칭(형용사+동물)으로 보인다. 같은 그룹 안에서 겹치지 않는다. 친구 그룹은 닉네임 | 두 온라인 그룹에서 같은 사용자의 별칭이 다르다(무작위, 같을 수도 있음) |
| GRP-11 | 언제든 나갈 수 있다. 친구 그룹의 마지막 구성원이 나가면 그룹을 보관 처리한다 | 나간 뒤 그룹 조회 → 404 |
| GRP-12 | 온라인 그룹에서 7일 동안 접속하지 않은 구성원을 매일 00:10(KST)에 내보낸다. 친구·1인 그룹은 내보내지 않는다 | `last_seen_at`이 7일 전인 구성원이 다음 처리 뒤 빠져 있다 |
| GRP-13 | 4명 미만이 된 온라인 그룹은 대기열 배정에서 가장 먼저 채운다 | 3명 그룹과 5명 그룹이 있을 때 새 대기자 → 3명 그룹 |
| GRP-14 | 온라인 그룹 구성원을 차단할 수 있다. 차단한 사람의 핑은 나에게 보이지 않는다 | 차단 후 핑 목록에 그 구성원이 없다 |
| GRP-15 | 신고 사유는 정해진 값만 받는다(`SPAM`, `HARASSMENT`, `OTHER`). 같은 그룹에서 서로 다른 2명에게 신고받은 구성원은 그 그룹에서 내보낸다 | 2명째 신고 → 대상이 그룹에서 빠진다 |
| GRP-16 | 1인 그룹은 초대 코드를 만들 수 없다 | → 409 |

### 5.3 기분 (MOOD) — 담당 B

| ID | 요구사항 | 완료 기준 |
| --- | --- | --- |
| MOOD-01 | 기분 값: `GOOD` 기분 좋음, `CALM` 편안해요, `OKAY` 보통이에요, `TIRED` 지쳐요, `DEPRESSED` 우울해요, `LONELY` 외로워요 | 그 외 값 → 400 |
| MOOD-02 | 하루 1개. 같은 날 다시 보내면 덮어쓴다 | 같은 날 2번 → 기록 1개, 나중 값 |
| MOOD-03 | 건너뛴 날은 저장하지 않는다(팝업을 하루 한 번만 띄우는 것은 기기에서 판단) | — |
| MOOD-04 | 낮은 기분이 3일 연속(오늘 포함)이면 가벼운 도움 카드를 띄운다. 닫으면 7일 동안 띄우지 않는다 | 11/14·15·16 모두 낮은 기분 → 16일에 카드 표시. 11/15 기록이 없으면 표시 안 함 |
| MOOD-05 | 내 기분 기록을 기간으로 조회한다(최대 93일) | — |

### 5.4 미션 (MIS) — 담당 B

| ID | 요구사항 | 완료 기준 |
| --- | --- | --- |
| MIS-01 | 미션 주제는 기획서 「미션 주제 목록」 20쌍을 시드 데이터로 넣는다. 각 주제는 밖·안 문구, 크기 방식(`TIME`/`COUNT`), 우선 기분 목록을 가진다 | 주제 20개 |
| MIS-02 | 오늘 미션을 처음 조회할 때 배정한다. 그 시점의 오늘 기분(없으면 `OKAY`)의 우선 주제 중에서, 최근 3일 안에 받은 주제를 빼고 무작위로 고른다. `OKAY`는 기획서 기분 매핑표대로 우선 주제 없이 전체에서 고른다. 후보가 없으면 전체 주제에서 같은 규칙으로 고른다 | 3일 연속 같은 주제가 나오지 않는다(1,000회 시뮬레이션) |
| MIS-03 | 한 번 배정한 오늘 주제는 바뀌지 않는다 | 같은 날 다시 조회 → 같은 주제 |
| MIS-04 | 크기는 기분 매핑표로 정한다: 고른 시간(5·10·20분)이 최대치이고, `TIRED`·`DEPRESSED`면 10→5, 20→10. `TIME` 주제는 분, `COUNT` 주제는 5→1, 10→2, 20→3(노래 주제는 1·2·4곡) | `DEPRESSED`+20분 → 10분 |
| MIS-05 | 사용자는 추천 크기를 바꿀 수 있고, 밖/안을 고른다. 기본값은 어제 고른 값 | — |
| MIS-06 | 시작하면 서버가 `started_at`을 저장한다. 경과 시간은 기기가 `started_at` 기준으로 계산한다 | — |
| MIS-07 | '다 했어요'는 하루 1회. 시작하지 않은 미션도 완료할 수 있다(정직 기반) | 같은 날 2번 → 409 `ALREADY_COMPLETED` |
| MIS-08 | 완료는 그 순간 내가 속한 모든 그룹의 오늘 완료로 반영된다. 오늘 이미 완료한 뒤 새 그룹에 들어가면 그 그룹에도 오늘 완료로 센다 | 완료 후 새 그룹 참여 → 그 그룹 오늘 완료 수에 포함 |
| MIS-09 | 미션 문구는 주제 시드의 밖·안 문구를 그대로 쓴다. 외부 AI로 문구를 만들지 않는다(같은 입력이면 늘 같은 미션) | 같은 주제·장소 → 같은 문구 |

### 5.5 핑 (PING) — 담당 B

| ID | 요구사항 | 완료 기준 |
| --- | --- | --- |
| PING-01 | 이모티콘 값: `CLAP` 👏, `CLOVER` 🍀, `MUSCLE` 💪, `SUN` ☀️ | 그 외 값 → 400 |
| PING-02 | 오늘 미션을 완료한 사람만 하루 1회 보낼 수 있다. 한 번 보내면 그 시점에 속한 모든 그룹에 간다 | 미완료 → 409 `MISSION_NOT_COMPLETED`, 두 번째 → 409 `ALREADY_PINGED` |
| PING-03 | 그룹의 오늘 핑 목록은 이모티콘만 준다. 보낸 사람·시각은 주지 않고 순서는 섞는다(누가 완료했는지 드러나지 않게, CHR-10) | 응답에 보낸 사람·시각 필드가 없다 |
| PING-04 | 핑을 받으면 그 그룹 구성원에게 웹 푸시를 보내지 않는다(알림 피로). 그룹 화면에서만 보인다 | — |

### 5.6 캐릭터 (CHR) — 담당 B

| ID | 요구사항 | 완료 기준 |
