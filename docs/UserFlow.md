## 2. 앱을 열 때

```
앱 열기
├ 쿠키 없음(계정 없음) → S01 스플래시 → 온보딩(3절)
│    └ S01의 "지금 도움이 필요해요" → S40 도움받기 (계정 없이)
└ 계정 있음 → 그룹 탭 S20
     ├ 오늘 기분 팝업을 아직 안 띄웠으면 → P01  (기기에 날짜 저장)
     │    └ 닫힌 뒤 → GET /missions/today (주제 배정)
     └ GET /checks/current 의 due = true 이면 → P01 다음에 P02
```

- P01은 하루 한 번만 뜬다. 기기에 마지막으로 띄운 날짜를 저장하고, `GET /me`의 `today`(서버 기준 오늘)와 비교한다.
- P01과 P02가 같은 날 겹치면 P01 → P02 순서다.
- 민감정보에 동의하지 않은 사용자에게는 P01·P02를 띄우지 않는다. 미션은 '보통이에요' 기준으로 배정된다.

## 3. 온보딩 (처음 1회)

```
S01 스플래시 → S02 서비스 설명 → S03 홈 화면 추가 안내
→ S04 닉네임 (여기서 계정 생성)
→ S05 선택 정보 (건너뛰기 가능)
→ S06 민감정보 동의 (동의 / 나중에)
→ S07 알림 허용 (허용 / 나중에)
→ S08 첫 그룹 고르기
    ├ 친구 → S09 만들기 또는 S10 코드 입력
    ├ 온라인 → S11
    └ 혼자 → 1인 그룹 생성
→ S20 그룹 홈 → P01 기분 팝업
```

- S03: 아이폰은 사파리와 홈 화면 앱의 저장소가 따로라, 홈 화면에 추가한 뒤 그 앱에서 S04부터 이어가도록 안내한다. 안드로이드는 '나중에'를 허용한다.
- S04 전에 앱을 닫으면 계정이 없으므로 다음 실행 때 S01부터 다시 한다.
- 온보딩 중 어느 화면에서든 도움받기로 갈 수 있다(상단 링크).

## 4. 매일 흐름

```
S20 그룹 홈
→ 오늘의 내 미션 카드 (주제, 밖/안 문구)
→ S21 미션 준비: 쓸 시간 고르기 → 추천 크기 표시 → 밖/안 → 시작
     └ "그냥 하나 골라줘" → 어제 고른 시간·밖/안으로 바로 시작
→ S22 타이머 (화면을 꺼도 startedAt 기준으로 이어짐)
     └ 타이머 없이 '다 했어요'도 가능
→ S23 '다 했어요' → 그룹별 "N명 중 M명" 갱신, 단계가 바뀐 그룹 표시
     → 핑 고르기 (선택, 건너뛰기 가능) → 내 모든 그룹에 한 번에
→ S20 (미션 카드는 '오늘 완료' 상태)
```

**S20 상태**

| 상태 | 미션 카드 | 그룹 목록 |
| --- | --- | --- |
| 미션 시작 전 | 주제 + '시작' | 그룹별 캐릭터·"N명 중 M명" |
| 시작함 | 경과 시간 + '다 했어요' | 같음 |
| 완료 | "오늘은 이 정도면 충분해요" | 같음 |
| 그룹 없음 | 미션 카드는 보임(개인 미션) | "그룹을 만들어 함께 키워요" + S28 |
| 온라인 대기 중 | 같음 | "함께할 사람을 찾고 있어요" 카드 + 대기 취소 |
| 오프라인 | 마지막으로 받은 미션 표시, 시작·완료 버튼 비활성 | 마지막 값 + "연결되면 갱신돼요" |

**가벼운 도움 카드:** `GET /help-card`의 `show=true`면 S20 맨 위에 1장. 누르면 S40, 닫으면 7일 동안 안 보임.

**캐릭터 완성:** `GET /groups` 응답에 `justCompleted`가 있으면 그 그룹을 처음 볼 때 S26을 한 번 보여주고 S27 도감으로 갈 수 있게 한다.

## 5. 주간 흐름

```
일요일 18:00 이후 첫 실행 (P01 다음)
→ P02 마음 점검: "지난 2주 동안…" 4문항, 각 4개 보기
     └ 닫기 → 이번 주에는 다시 안 뜸
→ 제출 → P03 결과
     ├ DEPRESSION / ANXIETY → 문장 + 24시간 채널 + 상담받을 곳 → S41 → 공식 페이지·전화
     ├ LOW_MOOD_DAYS → 문장 + 가볍게 들를 곳
     └ STABLE → 문장만
```

- P02·P03 모든 화면 하단에 "지금 힘들면 24시간 채널" 링크.
- P03에는 점수를 보여주지 않고 "진단이 아니라 참고예요"를 함께 쓴다.

## 6. 그룹 흐름

**친구 그룹 만들기·초대**

```
S28 → 친구 → S09 이름 입력 → 생성 → 초대 코드 화면 (복사 / 공유 시트, 만료일 표시)
S24 그룹 상세 → '초대' → 새 코드 (이전 코드 무효 안내)
```

**초대 코드로 참여**

```
S10 코드 입력 → 참여 → S24
  오류: 코드 없음 "코드를 다시 확인해 주세요" / 만료 "만료된 코드예요. 새 코드를 받아 주세요"
       / 6명 "그룹이 가득 찼어요" / 그룹 3개 "그룹은 3개까지 참여할 수 있어요"
```

**온라인 그룹**

```
S11 → 만 19세 확인(처음 한 번) → 들어가기
  ├ MATCHED → S24 (별칭 소개: "이 그룹에서 당신은 '산책하는 수달'이에요")
  └ WAITING → S20 대기 카드 → 배정되면 웹 푸시 → S24
```

**나가기·신고·차단**

```
S24 → '그룹 나가기' → 확인 ("캐릭터는 그룹에 남아요") → S20
S24 구성원 → S25 → 신고(사유 3개) / 차단 ("이 사람의 핑이 안 보여요")
```

## 7. 도움받기 흐름

```
탭바 '도움받기' (계정 없이도, 오프라인에서도)
→ S40
   ├ 선택 정보가 하나도 없으면 상단 배너:
   │   "정보를 입력하면 맞춤화된 복지 지원서비스를 찾을 수 있어요!" → S42
   ├ 1. 지금 바로 이야기할 곳 (24시간) — 항상 맨 위, 누르면 전화 연결
   ├ 2. 상담받을 곳 — 기기에서 필터·순서 적용
   └ 3. 가볍게 들를 곳
→ S41 상세 → 공식 페이지(새 창) 또는 전화
```

- 필터: 입력한 정보에 안 맞는 카드만 숨긴다. 입력하지 않은 정보로는 숨기지 않는다.
- 순서: `GET /help/signals`(계정이 있을 때)와 기획서 「순서 규칙」으로 구역 안 순서를 바꾼다.
- 오프라인: 캐시한 목록과 함께 "○월 ○일 기준" 표시.
- 서울 밖이거나 구를 모르면 정신건강복지센터는 '가까운 센터 찾기' 카드로 보인다.

## 9. 시연 흐름 (3분)

기획서 「시연 시나리오」와 같은 순서다. 시연 서버(`demo` 프로필) 기준.

| 단계 | 화면 | 준비 |
| --- | --- | --- |
| 1 | 앱 열기 → P01 '외로워요' | 은우 계정 쿠키가 있는 휴대폰 |
| 2 | S20: 미션 '햇빛 받으며 걷기', 시간 10분 → 추천 10분. 친구 그룹 + '아침 산책단' | 시드 데이터 |
| 3 | S21 → S22 → S23 '다 했어요' → 🍀 → '아침 산책단' 5명 중 5명 → 새싹에서 꽃으로 | 캐릭터 확정 합 48.2, 4명 완료 상태 |
| 4 | 마이 탭 시연 도구 '일요일 19시로' → 그룹 탭 → P01 기분 팝업(날짜가 바뀌어 다시 뜸) → P02 → 응답 → P03 "요즘 많이 지쳐 있었던 것 같아요" | 은우가 시드 시연 계정이어야 시연 도구가 보임 |
| 5 | P03 → 서울 청년 마음건강·마포구 정신건강복지센터 → S41 → 공식 페이지 | 은우 기기 선택 정보: 서울 마포구, 대학생, 26세 |
| 6 | 비행기 모드 → S40 열림 | 목록이 캐시돼 있어야 함 |

- 4단계에서 시계를 바꾸면 서버 날짜가 바뀌어 P01이 다시 뜬다. 시연에서는 P01을 건너뛰고 P02로 간다.
